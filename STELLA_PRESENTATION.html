Architecture

Built on Infrastructure
SXM Already Owns.

No external servers. No new vendors. No IT dependency. The entire platform runs inside Google Workspace using SXM's existing Claude Code enterprise account.

Frontend
🌐
Single URL

AM opens a URL in their browser. Google login auto-identifies them. No install.

📱
Single-File App

Full web application delivered by Google Apps Script — CSS, HTML, JS in one file. Works on any device.

🤖
Browser-Side AI

AI calls go directly from browser to internal LiteLLM endpoint. Data stays inside SXM's enterprise boundary.

Backend
⭐
Stella.gs

Orchestrator. Assembles Stella's system prompt with the AM's live campaign data and relevant KB sections before each AI call.

📊
StellaDB.gs

Data layer. One Google Sheet, one tab per AM. Auto-created on first login. Schema migrates silently when new fields are added.

📚
BillingKB.gs

Knowledge base. Billing workflow content injected into Stella's prompt when billing keywords are detected in a question.

Security note: No API keys are stored in code — all credentials live in Google Apps Script Properties (encrypted at rest). All AI calls route through SXM's internal LiteLLM gateway. Client campaign data never leaves the enterprise boundary.

The Ask

What We Need
to Go Further.

01 — API Access
Connect Stella to the Systems

Ads Manager, OMS, and Salesforce API access unlocks Phase 2. Live pacing, auto-ticket creation, and cross-system orchestration become possible overnight. This is the single highest-leverage unlock. Likely requires IT/Engineering collaboration on credentials and endpoint exposure.

02 — Broader Rollout
Scale from One AM to the Team

Stella is live and in use today. 83 AMs have access to AI tools but only 12 use them regularly. Stella's advantage is that it's purpose-built for CS workflows — not a general GPT. A coordinated rollout with a short enablement session can close the adoption gap fast.

03 — Knowledge Base Collaboration
Port the Team's Best GPTs into Stella

Three AMs have already built valuable GPTs — Trafficking, Campaign Monitoring, and Incremental Upsell. Porting their knowledge into Stella makes those tools available to the whole team in one place, rather than siloed on individual ChatGPT accounts.

04 — Dedicated Ownership
Someone's Full-Time Job

The CS North Star is a full-time role's worth of work. Building Stella, enabling adoption, coordinating with IT on API access, onboarding new agents — none of this scales as a side project. The infrastructure is proven. Now it needs a dedicated owner to take it org-wide.
