── PHASE 17: OOO COVERAGE ────────────────────────────────────────────────

Allows any AM to temporarily load a colleague's campaigns with full
read/write access, with Stella aware of the coverage context.

Stella.gs
  - buildCoverageStellaSystemContent(userMessage, coveredEmail, coverageDoc):
    New system prompt variant for coverage mode. Loads covered AM's campaigns
    via getCampaignContext(coveredEmail). Injects coverage notes/doc as
    "--- COVERAGE NOTES ---" section. Adds identity context block telling
    Stella who is being covered and in what capacity.
  - readGoogleDoc(url): Reads Google Doc text via DocumentApp.openByUrl().
    Throws descriptive error if Doc is not accessible.

Index.html (STELLA_VERSION → "17")
  CSS
  - .coverage-banner: amber (#b45309) sticky banner, flex layout with
    exit button.
  - .coverage-banner-exit: semi-transparent button inside banner.
  - .cov-doc-tabs / .cov-doc-tab: two-button tab switcher for
    Google Doc URL vs. paste content.

  HTML
  - navCoverage: "Cover for AM" nav item added to sidebar (hidden in seller
    mode alongside other AM-only nav items).
  - coverageModal: full coverage entry modal — AM email input, optional
    coverage doc section (Google Doc link or paste), Load Campaigns button.

  JS globals
  - _coverageMode (bool), _coveredEmail (string), _coverageDocText (string),
    _covDocTabMode (string): session-only coverage state, not persisted.

  JS functions
  - _getCampaignEmail(): returns _coveredEmail in coverage mode, else
    currentUser.email. Used in all saveCampaign / deleteCampaign calls.
  - openCoverageModal() / closeCoverageModal(): show/hide coverage modal.
  - switchCovDocTab(tab): toggle between URL and paste doc input.
  - startCoverage(): validates email, optionally reads Google Doc via GAS,
    then calls _finalize() to set coverage state and enter coverage mode.
  - _enterCoverageMode(): updates campaigns title and back-button text,
    calls loadCampaigns() (which short-circuits to _coverageLoadCampaigns),
    navigates to campaigns view.
  - _showCoverageBanner(covName) / _removeCoverageBanner(): insert/remove
    amber coverage banner at top of campaigns view.
  - _coverageLoadCampaigns(): loads covered AM's campaigns via
    getCampaigns(_coveredEmail); populates allCampaigns, refreshes views.
  - exitCoverage(): clears all coverage state, removes banner, restores
    title and back-button text, reloads own campaigns.

  Modified functions
  - loadCampaigns(): early-exit to _coverageLoadCampaigns when _coverageMode.
  - sendChat(): checks _coverageMode first; calls
    buildCoverageStellaSystemContent with _coveredEmail and combined
    supplement (coverage doc + any campaign context hint).
  - saveCampaignForm(), confirmDelete(), saveDetailSection(),
    _savePacing3P(): all now call _getCampaignEmail() instead of
    currentUser.email so edits land on the correct AM's tab in coverage mode.

── PHASE 14: OUTLOOK CALENDAR INTEGRATION (Claude Code Bridge) ───────────

First-pass Meetings widget using a Claude Code skill as a sync bridge.
The skill fetches events from Outlook via the outlook-calendar MCP plugin
and POSTs them to Stella's new doPost() endpoint. Works for the AM running
Claude Code; multi-AM solution deferred to Roadmap Item 26 (MSAL.js).

Stella.gs
  - doPost(e): new GAS endpoint. Accepts POST { secret, email, events }.
    Validates CALENDAR_SYNC_SECRET Script Property before writing.
    Returns { ok: true, saved: N } or { ok: false, error: "..." }.
    Uses ContentService.MimeType.JSON response.

StellaDB.gs
  - _getOrCreateCalTab(email): returns or creates a hidden per-AM
    [tabName]_cal tab in the DB sheet. Hidden on creation.
  - saveCalendarEvents(email, events): writes events JSON array to A1,
    ISO timestamp to A2.
  - getCalendarEvents(email): reads A1 (events) + A2 (syncedAt), returns
    { events: Array, syncedAt: string }. Safe on first call (no tab yet).

Index.html
  - _calEvents / _calSynced globals for calendar state.
  - loadCalendarEvents(): calls getCalendarEvents() via google.script.run,
    stores results, re-renders Meetings widget body in-place without full
    home re-render.
  - buildMeetingsBody(): renders based on state:
      null = loading spinner
      never synced + empty = "needs setup" placeholder with /refresh-stella-calendar instructions
      synced + events = grouped by day (Today / Tomorrow / day name),
        each event showing time range, subject, location.
        All-day events labeled "All day". Sync footer shows relative
        time since last sync.
  - buildMeetingsWidget(): now just calls buildWidgetCard + buildMeetingsBody().
  - _esc() / _relTime() helpers added for meeting card rendering.
  - loadCalendarEvents() called in getCurrentUser success handler.
  - New CSS: .mtg-day-header, .mtg-event, .mtg-time, .mtg-info,
    .mtg-subject, .mtg-loc, .mtg-sync-row, .mtg-empty, .mtg-loading.

~/.claude/commands/refresh-stella-calendar.md
  - New Claude Code skill file.
  - Reads STELLA_GAS_URL + STELLA_CALENDAR_SECRET env vars.
  - Instructs Claude to fetch next-7-days events from the outlook-calendar
    MCP plugin, format them to Stella's schema, POST to GAS endpoint,
    and report sync result. Includes one-time setup instructions.
